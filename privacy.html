Shorts Autopilot privacy policy

Last updated November 1, 2026.

Shorts Autopilot is a personal tool operated by Ray Kreisel. It is used only with Ray's own accounts.

What it accesses

With Ray's permission, it uses the YouTube Data API, the Meta (Instagram and Facebook) APIs and TikTok's Login Kit and Content Posting API to upload videos, set their details and schedule or publish them on Ray's own channel, accounts and Page, and to read back what was published so it can confirm each upload.

What it stores

The access tokens Google, Meta and TikTok issue, and a record of which video was published where. They are kept on Ray's own computer and, for the scheduled publishing job, as encrypted secrets in Ray's private GitHub repository. They are not shared with or sold to anyone.

Other people's data

Shorts Autopilot does not collect, store or process data about any other person.

Google API Services

Shorts Autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

YouTube API Services

Shorts Autopilot uses YouTube API Services. It uses them to upload videos to the authorizing user's own channel, set each video's title, description, tags, publish time and recording date, add it to that channel's playlists, and read back the channel's playlists and the status of the videos it uploaded. It does not read comments, analytics, subscribers or any other channel's data. Users of Shorts Autopilot agree to the YouTube Terms of Service, and the Google Privacy Policy applies to data Google holds about them.

TikTok

Shorts Autopilot uses TikTok Login Kit to let Ray authorize it, with the scopes user.info.basic (to show which account is connected) and video.publish (to post his own videos to his own TikTok account). It reads the account's display name and open ID only, posts the video file with its caption, and checks the post's status. It does not read followers, comments, messages, analytics or any other account's data. Use of TikTok is subject to the TikTok Terms of Service and Privacy Policy. Access can be revoked in the TikTok app under Settings and privacy, Security, Manage app permissions.

Data retention and deletion

The only data Shorts Autopilot stores is the OAuth token, kept until access is revoked, and the IDs of the videos it uploaded, kept so that it never uploads the same video twice and deleted when that series is finished. It stores no other YouTube API data. To delete everything, revoke access (below) and delete the Shorts Autopilot folder from the computer it runs on; you can also email raykreisel@gmail.com and the stored tokens and records will be deleted within 7 days.

Revoking access

Access can be withdrawn at any time from Google account permissions or Meta's Business Integrations settings, or TikTok's Manage app permissions.
