Shorts Autopilot privacy policy

Last updated November 1, 2026.

Shorts Autopilot is a personal tool operated by Ray Kreisel. It is used only with Ray's own accounts.

What it accesses

With Ray's permission, it uses the YouTube Data API and the Meta (Instagram and Facebook) APIs to upload videos, set their details and schedule them on Ray's own channel, account and Page, and to read back what was published so it can confirm each upload.

What it stores

The access tokens Google and Meta issue, and a record of which video was published where. These are kept only on Ray's own computer and are not shared with or sold to anyone.

Other people's data

Shorts Autopilot does not collect, store or process data about any other person.

Google API Services

Shorts Autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

YouTube API Services

Shorts Autopilot uses YouTube API Services. It uses them to upload videos to the authorizing user's own channel, set each video's title, description, tags, publish time and recording date, add it to that channel's playlists, and read back the channel's playlists and the status of the videos it uploaded. It does not read comments, analytics, subscribers or any other channel's data. Users of Shorts Autopilot agree to the YouTube Terms of Service, and the Google Privacy Policy applies to data Google holds about them.

Data retention and deletion

Shorts Autopilot keeps API data only as long as it needs it: the OAuth tokens until access is revoked, and the record of uploaded video IDs for as long as the series is being published. No YouTube API data is stored for longer than 30 days without being refreshed from the API. To delete everything, revoke access (below) and delete the Shorts Autopilot folder from the computer it runs on; you can also email raykreisel@gmail.com and the stored tokens and records will be deleted within 7 days.

Revoking access

Access can be withdrawn at any time from Google account permissions or Meta's Business Integrations settings.
